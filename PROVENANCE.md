`HD.PARTPIN_RANGE` geometry in the same sections is read from the shell's
`boards/*/base.xdc` and the `app/au{280,55c}_lb_guard/floorplan.xdc` guards.

## Deliberately excluded

| Not copied | Why |
|---|---|
| `app/flow_reduce/benchmark/{RUBRIC,RUN_PROTOCOL}.md`, `benchmark/conformance/` | An evaluation harness grades a developer; a guidance corpus must not contain the answer key. Reusable practice from them is in `prompts/00` and `prompts/06`. |
| `app/flow_reduce/tests/cocotb/test_vecavg_fast.py` + `run_vecavg_fast.py` | The pre-fix sibling of `test_vecavg_stress.py`, still carrying the hand-rolled `egress_collector` that shell commit `8718d45` replaced with `cocotbext-axi`'s `AxiStreamSink`. It is in no harness upstream — `benchmark/conformance/run_conformance.py` runs only the e2e and stress suites — so it never received the fix and still fails (`pkt 0 len 512`, expected 576: one 64-byte beat mis-scored, exactly the phantom "~27 % header drop" described in `docs/13` and `prompts/04`). Upstream that is a harmless orphan next to a harness that ranks it; here, with the harness excluded, it would have read as a peer of the corrected test in the one directory an agent consults for testbench patterns. A corpus that mandates library AXI agents must not ship a working counter-example of one. |
| Shell RTL beyond `rp_blk.v` | These DEPs consume a shell *package*, not a shell source tree. |
| `app/flow_reduce/verilog/`, `build/` | Generated; reproduced by `make compile`. |
| Board files for au280 / au55c | Out of primary scope; deltas are documented in `docs/06`. |
| Host driver sources | Documented as usage in `docs/15`, not vendored. |
